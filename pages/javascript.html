Leçon 1

Variables et types

On déclare une variable avec let (modifiable) ou const (constante). Les types de base sont les chaînes, les nombres et les booléens.

let nom = "Sara";
const age = 20;
let inscrit = true;

Leçon 2

Fonctions

Une fonction regroupe des instructions réutilisables. La syntaxe fléchée est la plus courte.

const somme = (a, b) => a + b;
console.log(somme(2, 3)); // 5

Leçon 3

DOM et événements

Le DOM représente la page. On sélectionne un élément avec querySelector et on réagit à une action avec addEventListener.

const bouton = document.querySelector("button");
bouton.addEventListener("click", () => {
  bouton.textContent = "Cliqué !";
});
