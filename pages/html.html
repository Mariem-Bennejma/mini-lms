Leçon 1

Structure d'une page

Toute page HTML commence par une déclaration de type de document, puis un élément html qui contient deux parties : head (informations sur la page) et body (contenu visible).

<!DOCTYPE html>
<html lang="fr">
<head>
    <meta charset="UTF-8">
    <title>Ma première page</title>
</head>
<body>
    <h1>Bonjour</h1>
</body>
</html>

Leçon 2

Balises sémantiques

Les balises sémantiques décrivent le rôle de chaque zone : header pour l'en-tête, nav pour la navigation, main pour le contenu principal, section et article pour organiser le contenu, footer pour le pied de page. Elles améliorent l'accessibilité et le référencement.

<header>
    <nav>...</nav>
</header>
<main>
    <section>
    <h2>Titre de section</h2>
    </section>
</main>
<footer>...</footer>

Leçon 3

Liens, images et listes

Un lien utilise a avec l'attribut href. Une image utilise img avec src et un texte alternatif alt obligatoire. Les listes se font avec ul (à puces) ou ol (numérotée).

<a href="https://www.w3.org">Site du W3C</a>
<img src="logo.png" alt="Logo du site">
<ul>
    <li>Premier élément</li>
    <li>Deuxième élément</li>
</ul>
