Leçon 1

Sélecteurs et couleurs

Une règle CSS cible des éléments avec un sélecteur (balise, classe .carte ou identifiant #menu) puis applique des propriétés.

h1 { color: #4f46e5; }
.carte { background: white; border-radius: 14px; }
#menu { display: none; }

Leçon 2

Flexbox

Flexbox aligne des éléments sur un axe (ligne ou colonne). Avec display: flex sur le parent, on contrôle l'alignement avec justify-content et align-items.

.menu ul {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

Leçon 3

Grid et responsive

Grid organise des éléments en lignes et colonnes. Les media queries adaptent la mise en page à la taille de l'écran.

.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(260px, 1fr));
  gap: 1.5rem;
}
@media (min-width: 768px) {
  .burger { display: none; }
}
